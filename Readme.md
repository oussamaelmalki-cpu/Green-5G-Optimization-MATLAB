# 🌱 Optimisation Énergétique (Green 5G) sous MATLAB

## 📖 Description
Ce projet simule un réseau 5G sous MATLAB et implémente un algorithme d'optimisation (Load Balancing & Sleep Mode) pour réduire la consommation d'énergie (Green IT).

## 🗂️ Contenu du projet
- `projet5G.m` : Simulation de base (sans optimisation).
- `optimiz.m` : Simulation avec l'algorithme d'optimisation. Génère le fichier CSV des résultats.
- `resultats_green_5g.csv` : Données exportées pour l'intégration avec Streamlit.

## 📊 Résultats
L'algorithme permet de réduire la consommation énergétique de **plus de 40%** lors des heures creuses en mettant en veille (Sleep Mode) les antennes inactives.
